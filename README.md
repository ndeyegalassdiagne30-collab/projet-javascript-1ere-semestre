# Projet JavaScript - Gestion des Inscriptions

Application web de gestion des inscriptions d'étudiants.

## Fonctionnalités
- Ajouter un étudiant
- Modifier un étudiant
- Archiver / Supprimer un étudiant
- Restaurer un étudiant archivé
- Rechercher et filtrer par formation

## Technologies
- HTML / CSS
- JavaScript Vanilla (ES Modules)
- LocalStorage
